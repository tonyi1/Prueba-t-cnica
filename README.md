PRUEBA TÉCNICA Aplicación Web de Gestión de Tareas
  Aplicación web desarrollada con HTML5, CSS3 y JavaScript Vanilla como prueba técnica.
  El objetivo es demostrar manejo del DOM, eventos, estado de la interfaz, buenas prácticas de frontend y control de versiones con Git/GitHub.
  
Funcionalidades
  Agregar nuevas tareas
  Marcar tareas como completadas mediante botón dedicado
  Eliminar tareas con confirmación
  Visualización de tareas en tabla
  Filtro de tareas:
    >Todas
    >Pendientes
    >Completadas
    >Contador de tareas pendientes
    >Persistencia de datos usando localStorage
    >Interfaz responsive (móvil y escritorio)
    
Tecnologías utilizadas
  HTML5 (etiquetas semánticas)
  CSS3 (Flexbox, responsive design)
  JavaScript (Vanilla)
  Git
  GitHub
